# Security Policy

## Supported Versions

Only the latest version on the `main` branch is actively maintained.

| Version        | Supported          |
| -------------- | ------------------ |
| 1.0.0-SNAPSHOT | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues privately by emailing **rahilrshk@gmail.com**
with a description of the issue and steps to reproduce it. Do not open a public
GitHub issue for security reports.

You can expect an acknowledgement within a few days. Once the issue is
confirmed and fixed, the fix will be released and the report credited unless you
prefer to remain anonymous.
